## What we build

The **iSDR** platform — a complete SDR transceiver stack for Android — plus the open
components it stands on:

- **iSDR** — the transceiver app: RX/TX, multi-mode demodulation, DSP audio chain,
  digital modes, logging, and remote access.
- **iSDR Drivers** *(GPL)* — USB device drivers for RTL-SDR, HackRF, HL2, and G2-class
  hardware, ported to Android.
- **iSDR Station** — the secure remote-access connector (self-managed WireGuard).
- **isdr-proto** *(MIT)* — the wire-contract library shared across the apps.
